# Portfolio Website

This is a portfolio website project built using Vite and React. It showcases various projects, personal information, skills, and provides features for theme switching and language selection.

## Features

- **Project Showcase**: Displays various projects with images and brief descriptions.
- **Personal Information**: Includes a section about yourself and your background.
- **Skills Section**: Lists your technical skills.
- **Contact Details**: Provides a way for visitors to reach out.
- **Theme Switching**: Allows users to toggle between light and dark themes.
- **Language Selection**: Users can switch between different languages.

## Getting Started

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd portfolio-website
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm run dev
   ```

5. Open your browser and visit `http://localhost:3000` to view the portfolio.
